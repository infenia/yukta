Try the idea of a workflow before you install anything. Boxes light up in order, and you can make one fail to see where the failure goes.

**How to use it:** pick a preset (or edit the JSON), click one node then another to connect them, and use **Run** or **Step**. Shift-click a node, or use its Fail button, to make it fail.

<WorkflowPlayground />

<Warning>
  This is a **simulation in your browser**. No server is contacted, and a green run here does not mean the real server will accept your workflow.
</Warning>

It leaves out plugin work, retries, time limits, message streams, approval waits and persistence. A failed node fails at once and follows its `error` edge if it has one.

Ready for the real thing? Follow the [Quickstart](/quickstart), or read [Failure handling](/concepts/failure-handling) to see what a real run adds.
