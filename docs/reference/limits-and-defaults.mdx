<Info>
  **In plain terms:** the numbers behind the server: what is capped, what the default is, and which setting changes it. Check it before you plan for large workflows or heavy traffic.
</Info>

This page collects the numbers that bound a Yukta server: fixed ceilings, default values and the setting that changes each one. "Fixed" means no setting changes it. "Off" means the feature is disabled until you set it.

<Note>
  Storing state on disk (`yukta.session.store-type=file`) is part of the **Plus** edition (AGPL-3.0-only). Build it with `-Pyukta.edition=plus`; the Community build refuses these settings at start-up and keeps state in memory. See [Licensing and editions](/reference/licensing).

  Yukta is in alpha (`0.1.0-alpha.2`), so defaults and limits may change before v0.1.0.
</Note>
