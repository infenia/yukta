### ⚠ BREAKING CHANGES

* **core:** the signal API is removed from plugin-api, core, REST and MCP. Phases 4 and 5a to 5e ship together.
* **cli:** move CLI, mod, examples and docs off the signal API ([#1804](https://github.com/infenia/yukta/issues/1804)) (#1866)
* **plugins:** ask for input through the gateway, add ASK_INPUT and ask_for_input ([#1792](https://github.com/infenia/yukta/issues/1792)) (#1859)
* **core:** a custom supervisor bean with an id outside the rule no longer starts the server; stored ids that break it are renamed by V8.
* **core:** a custom supervisor bean with an id outside the rule no longer starts the server; stored ids that break it are renamed by V8.
* **core:** GET /api/control/workflows/{w}/nodes[/{n}/heartbeat] and POST .../command need ?sessionId=; yukta-cli controlbus nodes|heartbeat|command need --session.
* **core:** run and node times are UTC ("Z") instead of the server's offset, and the since/until filters need an instant such as 2026-07-19T00:00:00Z.
