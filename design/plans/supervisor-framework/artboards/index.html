Supervisors: artboards for review (#2153)

Built from the running app: its compiled CSS, header, icon rail and the Plugins page layout, so what you see is how it renders. Each frame is a real page in screens/; open it to see it full size, and add ?theme=dark for dark. The phone frame is a 390 px wide page, so it shows the app's own phone layout (bottom tab bar).

Accessibility: the pages use the app's own components: visible focus, disabled controls keep their reason as text, every status is an icon plus a word, and the app's reduced-motion guard applies.

Priorities: viewing first. Supervisors are usually configured by an AI agent over MCP, the CLI or the API, so the pages show what was configured, by whom, and how it fits together; editing is a secondary action. Decision makers (Rules, External system, Program on this server, Workflow) are what a supervisor decides with, one per supervisor, shown like Plugins. The External system gets each signal posted to its url or reads it over the agent API, and decides through the agent API.
