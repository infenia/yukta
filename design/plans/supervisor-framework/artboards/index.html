Supervisors: artboards for review (#2153)

Built from the running app: its compiled CSS, header, icon rail and the Plugins page layout, so what you see is how it renders. Each frame is a real page in screens/; open it to see it full size, and add ?theme=dark for dark. The phone frame is a 390 px wide page, so it shows the app's own phone layout (bottom tab bar).

Priorities: viewing first. Supervisors are usually configured by an AI agent over MCP, the CLI or the API, so the pages show what was configured, by whom, and how it fits together; editing is a secondary action. Decision makers (Rules, Agent endpoint, Webhook, Program, Workflow) are the integrations a supervisor decides with, shown like Plugins.
