Supervisors

Who watches your workflows, what each may do, and who they answer to. Usually set up by an AI agent over MCP, the CLI or the API.

Supervisors6

Edit release-guard

For a quick change by hand. Most changes come from an agent; the same edit over MCP or the CLI is below.

Change it from your agent (the usual way)
MCP   save_supervisor  {"id": "release-guard", …}
CLI   yukta supervisors show release-guard
      yukta supervisors assignments release-guard
API   GET /api/supervisors/release-guard

New supervisors are made the same way (New, then the same form) and start in dry run. What it owns is changed on its Owns tab.
